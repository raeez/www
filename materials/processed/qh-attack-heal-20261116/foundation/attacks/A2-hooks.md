## Constraints an atlas mount must respect (from the hooks above)
- Namespace every class (for example `atlas-*`). `.grid`, `.card`, `.term`, `.filter`, `.row`, `.rows`, `.statement`,
  `.question`, `.failure`, `.gloss`, `.theme`, `.nav`, `.find` and `.mark` are all live hooks (rows 1, 5, 10, 15, 16, 25).
- Inline atlas JS and CSS at build time. The CSP (py:729-730) forbids external scripts, and baseline py:721-722 concatenates
  only status.css, status-print.css and status.js, so the baseline has no asset hook.
- A nav item must be `href="#<section id>"` (row 18). Its section is not searchable until status.js SCOPES is extended
  (row 24, cross-lane).
- `main details` inside the atlas will be opened for print (row 19). Print rules for the atlas belong in status-print.css.
- Reader-visible atlas labels must pass audit.py FORBIDDEN. Pattern audit.py:24 `(?<![\w.])(T|N|B|R|P|C)\d{1,3}` rejects
  labels such as "C2" or "P1".
