# Source provenance

The seven accessible papers were received as part of *Research on Institutions, Claims, and Markets*, dated 8 September 2026. Their Markdown, TeX, and reference metadata were copied unchanged into `materials/raw/2026-09-09-accessible-papers/` before website conversion.

`compiler/reader-papers.json` records the exact Markdown SHA-256 digests, titles, and reading order. `compiler/build-reader-papers.py` verifies those digests before rendering through the existing `compiler/template.html`. The Markdown body remains complete; the title moves to the article header, mathematics becomes MathML, and verified bibliography destinations can be added without changing citation text. Website metadata, reading-sequence navigation, and the writing index are presentation material.

The website publishes HTML. No PDF is imported or published by this build. Source copies and build controls are excluded from GitHub Pages.

The two fifth-level subheads in *Prices, Information, and Clearing Risk* render as third-level HTML headings beneath their second-level sections. Their text and the retained source remain unchanged.
